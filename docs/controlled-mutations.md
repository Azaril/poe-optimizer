# Retired finite-catalog workflow

The `search-experimental` command, ControlledMaceCatalog / PreparedMaceCandidates APIs,
old Mace search problem schemas and dedicated candidate benchmark were removed during
[architecture migration](architecture-migration.md). They are not compatibility aliases
for another command. Their historical implementation and measurements remain in Git and
[the implementation record](implementation.md).

The remaining [graph search](passive-equipment-assembly.md) is still a restricted Spark/Mace
implementation. The target is [owned semantic input and domain rules](domain-architecture.md),
not another profile. See [retirement inventory](legacy-retirement.md) for the remaining work.
Independent numerical fixtures and useful candidate laws are retained in tests.

## Strategies and accounting

Generic scheduling, budgets, objectives, candidate verification and archives remain in
[the search kernel](search-kernel.md). Removing the finite product does not remove them.

## Requirement validation

The retained domain keeps level/attribute/support requirements and separate ordinary and
ascendancy point budgets. Diagnostic evaluation and search legality remain distinct.
Unsupported or illegal candidates cannot become valid by changing the CLI command.
