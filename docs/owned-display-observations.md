# Derived item display observations

**Status:** Implemented import boundary; not numerical or whole-item coverage.

PoB exports some recomputed totals beside actual item inputs. The owned model must retain
provenance without importing those totals as base rolls and counting their inputs twice.
The import adapter therefore classifies reviewed numeric preamble lines as observations;
the native evaluator continues to consume owned definitions and actual build inputs.

## Acquisition and compilation

The optional reference adapter independently authenticates and constructs the pinned base
catalog, then projects finite facts: weapon-branch truthiness, armour-table numeric fields,
Spirit/Charm Slots field presence and known defence-header base-retarget exceptions. The
original base catalog v1 stays byte-for-byte unchanged. A separate catalog has its own
identity and acquisition evidence. Source names and compatibility facts stay in the offline
adapter/compiler; Core gains no source fields or UI state.

The native compiler accepts those finite catalog bytes, reviewed metadata-only line recipes,
and a checked predecessor package. It binds exact bytes and predecessor identities, locates
exact literal base headers with one template emission, and derives finite template sets.
Defence observations require the armour branch with no active weapon branch or known
retarget exception. Resource observations require finite corresponding base fields; zero
counts as present. Unknown shapes and missing compatible bindings cannot authorize rules.

An artifact hash is integrity evidence, not source authentication. The exporter authenticates
acquisition independently. The authored request remains a reviewed declaration about source
grammar: labeling an arbitrary rule as a defence does not prove its semantics. Pinned-source
reference tests support the six production declarations. Caller-authored owned builds do not
need this compatibility adapter.

## Attribution

Source policy v7 retains v6 flags, metadata and member prerequisites, and adds template-bound
preamble observations. Existing v3-v6 encodings, identities and empty-observation work budgets
remain unchanged. A declaration references a Metadata-only Unresolved rule, a semantic field
key shared by aliases, and a finite, canonically sorted list of known templates. Numeric syntax comes from the
injected checked line recipe. Production declarations accept unsigned integer spellings.

Admission requires a unique structurally selected compatible base, valid captures, no earlier
unresolved source problems, and a fresh preamble before any `Implicits:` declaration or parsed
member. Repeated fields, including aliases, remain pending. Tagged/escaped text, wrong or
unknown templates, malformed values and possible preceding-line consumption cannot become
observations. Raw text and spans remain in the sidecar; no numerical parameter is emitted.

Validation reuses sorted template indexes and exact previously validated lists. V7 also
merges requested default bindings against the constructor's already checked template index;
older dialects retain their prior traversal. Actual comparisons and list equality checks
remain charged, and tighter encode limits retain the combined cached cost. The existing
schema-work cap is unchanged; no runtime data lookup or source execution substitutes for
these proofs.

Ending the reviewed preamble at `Implicits:` is conservative: source can accept a display
immediately after that declaration before its first actual member. Once member parsing has
started, the same header can reach the modifier parser. This implementation does not replay
that source lifecycle to widen admission. Aliases that can retarget bases also remain outside
the production declarations.

## Real state and remaining work

`Corrupted` is a real item input, unlike these display totals. It needs a separate semantic
Boolean parameter and occurrence-attribution contract. All four supplied original markers
still have possible preceding-line consumption; recognizing the word alone cannot admit the
value. Do not infer absence=false from an incomplete envelope or conflate `Twice Corrupted`
with a reviewed single-Boolean contract.

This phase removes only proved display-prefix uncertainty. Modifier collection/order,
allocation legality, missing effects, actor/action resolution and numerical parity remain
separate gates. All five original builds and all 110 reference query rows remain required.
