# Unconditional passive minion damage

This family adds 41 data-authored contribution programs to existing passive
definitions. They contribute the source's unconditional `Minions deal X% increased
Damage` value to the existing Player channel `1d33`; the existing exact Sniper actor
receiver reads that channel into `1d34`. It adds no definition IDs, schema changes,
operations, runtime source parsing, or new receiver families.

The reviewed default-node family includes 40 ordinary nodes and one ascendancy
node. Original pool membership and scope are retained. Alternate passive views,
unlock-dependent nodes, conditional Command damage, and every other node line stay
outside this family. All 41 program owners retain their prior Partial closure,
including the 20 nodes with a single visible line. An authored numerical program
does not establish complete owner coverage.

`bindings.json` maps owned nodes to evidence-only source IDs, amounts and pools.
`dependencies.json`, `dependency-rules.json`, and `receivers.json` retain exact
predecessor dependencies. `extension.json` appends the contributions without
changing those dependencies. It preserves the predecessor's explicit V15 registry
and application records; the default registry alias remains V14.

`source-records.json` preserves the 41 complete static source modifier rows from
the authenticated fresh physical-damage witness. These rows are authoring evidence,
not a runtime lookup table. `authoring.json` binds the Pain Offering predecessor
`922ddfc5…` and both passing 37-case/38-load JIT observations. The distinction between
static and runtime evidence matters: all 41 source definitions were inspected, but
Original05 allocates ten of them. The actual Basic Attack consumer sees those ten
contributions totaling 68 percentage points. Removing source node 95 also prunes 8737,
leaving eight contributions totaling 48. Command node 25927 is not an unconditional
member and is not admitted by this family.

Native component tests retain the authored programs and exact Player-to-Sniper
receivers. Their explicitly unpublished fixture closes a finite contribution
inventory, omits graph reachability, and supplies the existing intrinsic Sniper
fixture's final gem levels. Tests exercise all 41 amounts, the measured 10/68 and 8/48
inventories, ordinary loadout activation, distinct ascendancy points, two exact
recipients, missing coverage, reused scratch and parallel execution. The publication
test keeps the complete production schema and all broader Partial declarations.

This is one producer family, not a complete physical-damage calculation. Pain
Offering activation/scaling, support preparation and final inputs, other damage
producers, conversion/gain, damage stages and metric routing retain their own
obligations. The five original builds remain Pending; this family grants no
whole-build parity or successful evaluation claim.
