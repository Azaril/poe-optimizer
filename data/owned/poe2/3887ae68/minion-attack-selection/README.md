# Intrinsic attack source selection

This packet connects four existing Basic Attack routes to one shared source
decision. The existing native Fixed policy selects the exact Action's Actor.
Damage minimum, damage maximum, attack rate and critical chance retain their
original Stat bindings and numerical producers. Accuracy and the intrinsic
added-damage percentage route are unchanged.

The [source review](source-review.md) and retained constructed catalog establish
the admitted intrinsic-only source domain. Publication also checks the complete
owned supply census for this output: its Actor, generated Skill, provider slots
and direct-selection prohibition. A new supplier requires renewed review. An
example build's observed weapon branch alone would not justify this selection.

Only the selector inventory becomes Complete. Numerical routes, rule owners,
queries and complete-build coverage retain their independent gaps. A missing
value from the selected Actor stays unavailable; no alternative source or zero
is substituted. This adds no definition, formula, execution kernel or source
language behavior to native evaluation.

The optional PoB test reuses the existing bounded catalog constructor to acquire
the proof. The pure retained-evidence checker is shared by acquisition and native
publication tests. Its Lua metadata and original-source names stay offline.
Publication uses the existing compact successor operation and verifies that
reversing this one routing declaration and its provenance row reproduces the
entire predecessor input.

Validation commands and the current published package are recorded in the
[implementation checkpoint](../../../../../docs/implementation.md). Ordinary
Engine replay tests exercise this same routing through public native APIs,
including separate Action occurrences, missing selected values, reused scratch
and four-worker execution. These are component checks, not final DPS or a
complete build.
