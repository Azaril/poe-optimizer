# Physical single-support input inventories

This optional normalization policy proves concrete physical Gem parameter-list
membership for a finite, reviewed source grammar. It preserves the existing
corruption inputs and intrinsic fields. It adds no definition, scalar value,
rule program, support application, or numerical result.

`inventory.json` contains all 514 identities from the existing reviewed
`support-gem-inputs/policy.json` domain. Every row joins one exact catalog physical
Gem identity to its owned Gem definition, known physical SupportAssignment role,
single primary support effect, and two existing corruption parameter slots.
Constructed or declared additional effects/stat sets are outside this domain.
The selected example builds do not define the allowlist.

`authoring.json` binds the exact requested-metric predecessor, schema, registry,
role package, mapping, source catalog, normalization policy, and reviewed source
artifacts. The publication helper computes the public scalar-input commitment
from that exact prior, constructs `PobFreshSingleSupportV1`, and records the
resolved policy in provenance. The published policy can be saved independently
for review without reimplementing its canonical digest algorithm.

The source proof accounts for every admitted Gem attribute and its enclosing
context. Exact physical identity, known intrinsic/scalar conversions, count 1,
enabled support semantics, and the reviewed global/legacy stat-set forms are
required. Extra attributes, namespaces, children, ambiguous identities, unknown
values, nondefault count/global settings, child stat-set maps, and group part
overrides remain outside the initial grammar. Failure retains existing known
assignments and the Pending concrete list; it does not substitute defaults.

The intended complete inventory contains only the two already converted physical
corruption parameters. Level and quality remain intrinsic Gem fields. Support
activation, targets, origin order, effects, generated skills, group choices and
usage remain distinct records and obligations. Living Lightning II and Concussive
Runes remain outside the single-support domain.

Publication is normalization-only. Every static Gem parameter declaration and
rule-owner closure remains exactly as before, including Partial coverage. The
checked full endpoint preserves the entire previous schema, registry, rules,
mapping, source evidence and provenance; only the new optional policy, dependent
tree commitment and explicit provenance row may change. All 110 query rows remain
byte-identical.

The real regression must compare all imported objects, including inactive groups,
with an injective local-ID correspondence for retired issue allocations. The
current domain census is 337 imported occurrences and 180 selected occurrences;
successful proof, rather than those counts, determines which lists may complete.
No complete-build or native numerical parity follows from this input inventory.
