# Intrinsic support-source domains for all eight Classes

This packet reviews every Class in the pinned PoE2 tree, not only Original05's
Sorceress. It supports `AuthoredAssignmentsOnly` on the existing Class owners
`0a1e`–`0a25`. It adds no IDs, formulas, allocation history or numerical coverage.
All eight current rule owners remain Partial; their existing sixteen programs
retain the current Count attribute channels and unarmed baseline outputs.

`evidence.json` pins eight existing full source archives and five existing
semantic artifacts. No source archive is duplicated. The maintained Rust proof
in `class_support_source.rs` reads those files with byte and inflation bounds;
it executes no Lua, historical publisher or source parser. The corresponding
`class_support_domains.rs` checks the actual maintained release and evaluates
all eight owners through the native rule engine.

The source proof connects the complete raw tree JSON Class array to the complete
executed `tree.lua` Class literal at lines 274–776. A finite, closed field-shape
serializer covers every Class, background and Ascendancy reference field. It
rejects unknown fields, duplicate or changed identities, altered source values
and nested behavior. The Witch's `replace`/`replaceBy` Ascendancy relationships
remain intact references to separately owned definitions. Neither those
references nor the Class's selected start node are treated as intrinsic Class
support suppliers.

The complete PassiveTree constructor (59–446), complete SelectClass method
(655–678), and complete CalcSetup environment constructor (717–2309) are pinned.
The reviewed paths rekey Classes by `integerId`, select their separate root and
Ascendancy, and contribute only the three Class base attributes. The retained
tree has no `characterData`, so CalcSetup's explicit `classes` fallback is the
applicable source. The whole nine-row unarmed table (`Data.lua` 626–636) is
reconstructed from the pinned catalog, including the explicit source-zero Scion
exclusion. The critical-strike value is checked against the imported
`characterConstants` value 500 divided by 100. Source zero is not an invented
ninth native Class.

Foreign effects remain separate. The weapon-selection branch prefers supplied
equipment and can apply Hollow Palm or Facebreaker modifiers from other owners.
Configuration, cached databases, items, allocated passives, skill groups and
cross-linked supports retain their own obligations. The evidence includes actual
`ExtraSupport` and `LinkedSupport` factories and consumers as positive contrasts;
the proof does not infer absence from empty program lists or from missing
numerical coverage. The shared Player Actor and Encounter domains are not
certified here, and completing these eight intrinsic domains does not complete
the composed build's support census.

The retained Class and intrinsic-attack policies describe source-field identity;
they are not replayed as historical compilers. The maintained tests bind those
fields to the current Count and scalar outputs, preserve all five unchanged
originals and their source selections, and keep Original05's five Pending
requirements. Whole-build parity and executable evaluation-bundle readiness
remain separate checkpoints.

New evidence JSON uses UTF-8 without a BOM and LF line endings. Archived upstream
source bytes retain their original identity.
