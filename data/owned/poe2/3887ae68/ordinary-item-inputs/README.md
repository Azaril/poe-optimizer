# Ordinary physical item inputs

This injected input contract preserves four raw physical facts for the reviewed
Rope Cuffs and Tattered Robe template definitions: rarity, corruption, an explicit
level-requirement override, and socket capacity. It adds five shared rarity
Options (`311f`–`3123`) and eight item parameter slots (`3124`–`312b`). No Stat,
rule program, calculated total, or coverage declaration is introduced.

The bound normalization policy uses the existing complete ordinary-item source
proof and exact opaque-header captures. Rarity is decoded by a finite Option
table; `LevelReq` is an integer raw override, independent of the derived final
requirement. The schema permits omission of the raw override, but this first
source grammar requires its explicit header. Capacity is separate from occupied
augment membership. Fresh setter-exclusion proves the admitted corruption value;
the legacy colon-header default mechanism is not used for bare corruption flags.

The first source domain is fresh ordinary rare construction with reviewed saved
affix metadata, explicit empty augments, and one completely converted explicit
modifier. It rejects ambiguous, alternate, duplicate, malformed, or unaccounted
physical input paths. Crafted state is retained as a construction witness; it
is not inferred from English item text or copied into a computed runtime channel.

`extension.json` preserves both existing Partial template parameter declarations
while appending the four slots to each. All template programs and their Partial
coverage remain unchanged. Completing a concrete imported parameter list does
not establish complete static input schemas, final item requirements, local
defence calculations, or whole-build evaluation.

The Rust publication helper binds the policy to the exact checked predecessor,
extends through the existing allocation/membership validator, preserves every
earlier provenance row, and assembles a full endpoint. Its regression compares
all five original requests and all 110 query rows, with an injective local-ID
correspondence for the two retired source parameter obligations. Source witnesses
remain optional PoB reference tests; the ordinary publication path executes no
PoB calculation code.
