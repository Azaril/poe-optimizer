# Attribute step consumers

This packet adds six shared native consumers of the existing pass-specific Count
contributions. It does not make an original build executable. Production BASE/INC
membership remains Partial and contains no authored ranks; effective MORE factors
have explicit Partial owners with no producer or default value. Complete original
build evaluation remains 0/5.

The three first-pass Integer outputs are `3321`–`3323`. The second pass produces
the existing final attributes `1d2e`–`1d30`. Six independent effective-MORE factor
Stats occupy `3324`–`3329`. All inputs and outputs are Actor-owned typed channels;
the receiver inventory applies these consumers to the Player. Names and IDs are
injected data, not a build or class dispatch in Rust.

Each receiver reads its actual BASE and INC occurrence query plus its own effective
MORE factor. An exactly zero BASE returns zero without demanding INC or MORE.
Otherwise it evaluates `BASE * ((1 + INC / 100) * effective_MORE)`, adds one half
Count, floors to one Count, clamps to zero, then converts to bounded Integer.
Clamping precedes conversion so a sufficiently negative intermediate still yields
zero; positive Integer overflow remains a failure. The packet does not choose how
nonempty MORE contributions are grouped, rounded or associated.

The twelve V21 queries contain fixed named groups with Partial empty member lists.
There are no production source ranks, node-ID sorting rules, scalar subtotals or
factor-one producers. A missing actual member fails candidate binding; Partial
coverage refuses complete evaluation. An absent effective-MORE producer remains
unresolved. None of these cases becomes zero or one.

These are six immutable scalar outputs over the ordinary incoming streams. They
do not implement conditional comparison snapshots, C0 defaults, shared query
limits, mutable source output state or convergence. Current ordinary donors emit
to both passes without reading prior attributes. A future donor that reads an
earlier snapshot needs its own explicit stage-bound invocation. No cyclic read of
a final attribute substitutes for that contract.
