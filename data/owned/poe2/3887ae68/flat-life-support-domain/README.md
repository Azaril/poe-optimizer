# Fixed-Life intrinsic support source

This packet justifies the intrinsic support-source domain of Modifier
`def.0000000000003100`. It does not certify complete Life values, complete item
conversion, incoming contributions, or whole-build execution.

The maintained proof checks **every live item-line emitter** of that identity,
independently of the selected build. There is exactly one: the retained
`fixed-life` rule. Its full pattern, captures and 24 roll assignments must remain
identical to the reviewed rule. The admitted grammar is a literal `+`, an
unsigned integer from 0 through 1,000,000, and ` to maximum Life`, under the
existing item-line whitespace policy. The exact source guard requires no source
scaling tags, an initial scalar of one, no generated buff members, and that
integer bound. The proof also retains the source layout, category construction
and twenty explicit source-property projections. Parsed record tags and source
property tags are separate; the word “Life” does not supply a property flag.

The evidence file pins existing artifacts and complete archived source files;
it adds no duplicate archives. The existing item-template proof authenticates
the complete Item build/slot constructors, their six intrinsic output sites,
ModList/ModStore/ModTools record construction, and the real `ExtraSupport` and
`LinkedSupport` factories and consumers. This packet reuses those bodies, not
the templates' domain declarations. Additional authenticated spans cover:
