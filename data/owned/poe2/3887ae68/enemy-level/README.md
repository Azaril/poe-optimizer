# Default configuration enemy level

This optional Import profile supplies the existing `EnemyDraft.level` field for
a reviewed fresh configuration branch. Field names, expected level and source
commitment are injected by `policy.json`. The native evaluator receives a typed
enemy level and does not load PoB or interpret its configuration callbacks.

The five original fixtures select ConfigSet 1 and save a numeric enemy-level
placeholder of 82 without an explicit enemy-level or boss-mode input. In pinned
PoB, fresh construction installs the default Pinnacle mode; its callback resets
the placeholder before resolving the actual enemy actor level. The saved number
alone is therefore insufficient evidence. `owned_enemy_level_source` exercises
the complete loader in both JIT modes and observes the MAIN and CALCS actors.

Admission requires unambiguous plain configuration containers, canonical numeric
set identities, exact typed rows, the injected absent-input guards, and the
reviewed placeholder value. Unsupported overrides, missing placeholders,
duplicates, aliases, conflicting encodings and unknown structure stay Pending.
Each configuration is checked independently. An unselected set cannot supply a
different set's value. Omitting the profile preserves historical normalization
bytes and allocation behavior.

Publication adds one explicit provenance entry and rebinds the existing tree
policy to the changed normalization commitment. It changes no definition,
registry entry, numerical program, query or source mapping. The CLI regression
compares all five unchanged saved selections and every unrelated draft/sidecar
relationship, with exactly one enemy-level obligation removed per original.

Encounter identity and mechanics, external assumptions, usage preferences and
configuration/reward inventories remain unresolved. Boss-stat default levels
and actual enemy actor levels are distinct; this profile does not infer either
from the other. Completing this field is not a complete build evaluation.

The source-validation record in `authoring.json` must be marked passed only
after the complete-source witness succeeds. Publication refuses a pending record.
