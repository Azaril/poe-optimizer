# Secondary source-switch component evidence

This packet investigates one finite Import accounting candidate: a saved
`enableGlobal2` has no indexed consumer when the complete final source
`grantedEffectList` contains exactly its primary effect. It grants no Import
receipt, native parameter, execution permission, numerical coverage or
whole-build parity.

The ordinary optional-PoB Rust target executes pinned source components in
fresh JIT-off/on VMs. It authenticates nine complete upstream source bodies
against the existing manifest, thirteen bounded spans, full catalog/declaration
correspondence, the two unchanged selected Original05 source rows, the reused
BuildExport archive and upstream license. It creates no reports or subprocesses.

The actual `Data.setupGem` constructor, `Common.copyTable`,
`Common.isValueInArray`, `Data.processMod`, `BuildExport.activeSkillGems`,
`CalcDefence.getActiveSkillCount`, saved-switch decoder and three SkillsTab
visibility consumers execute unchanged. The exact CalcSetup admission loops
and predicate run with an explicitly synthetic identity-only body; the complete
active-skill factory, modifier preparation, reservation and FullDPS do not run.
Wrappers supply only the stated component inputs and host objects.

The real anchors are Ice Nova and Firebolt. Both have multiple actual stat sets
and one constructed effect. Additional stat sets are not additional effects.
The complete Skeletal Sniper declaration is a real negative control: it retains
an unresolved Command reference even though source construction produces a
one-entry resolved list. That observed length never certifies complete absence.

Synthetic controls alter Vaal status, flags, effect declarations, display order
and lists. They are not claimed to be legal game states. A metatable access probe
returns the supplied secondary value while counting actual consumer reads.
Positive two-effect controls require observed reads and changed behavior, so
zero reads in singleton cases are not accepted from an unexercised observer.
Source `processMod` receives a synthetic GlobalEffect modifier to test the real
metadata writer; this does not prove that modifier reaches either real skill.

The singleton controls include absent, false and true secondary values, absent,
false and true global metadata, and both Vaal states. The count query uses the exact primary
table and a physical count of three, distinguishing it from the source fallback
of one. Even the Vaal branch cannot reach index two in that finite domain.
Primary-switch suppression remains separate and is explicitly tested.
An additional exact-primary-true control retains admission across those metadata
states while checking physical counts zero and seven. Separate enabled, support
and hidden controls still suppress admission. A direct count call is explicitly
not an admission check; its separate fallback behavior remains observable.
No conclusion extends the true domain to a false, nil or missing primary switch.
Raw serialization and UI state still preserve/read the saved secondary field.
Non-consumption here concerns the listed indexed admission/count/visibility
consumers; it does not justify erasing that field from the retained source.

The conservative test-only candidate predicate checks declared additions,
post-constructor indexed additions, full final table membership, primary table
identity and the resolved additional-effect list. It rejects declared-but-missing
references, index gaps, sparse late additions, duplicate/second effects,
constructor-generated Barbs additions and inconsistent parallel lists.
Display-order controls use the actual constructor to move the primary to index
two and demonstrate that the secondary switch then controls that exact effect.

These tests do not implement a production matcher or authorize trusting a bare
evidence digest. Current Import receipts deliberately exclude this field; the
source-proof transport decision is separate. Primary global-effect meaning,
Ice Nova ground/infusion mechanics, generated provider reconstruction, support
semantics and all missing Command mechanics remain unresolved. No old sealed
packet, production data schema or native model is changed.
