## Projection format and reconstruction

- `reports` pins both complete raw reports. `metadata` equals either report with
  its `cases` field removed; this retains source-file hashes and the original
  witness's explicit limits.
- `tracked_files` pins the five original XML fixtures, source manifest, Rust
  witness and its four authentication/loader/observer modules. Pins describe
  exact UTF-8 bytes. All currently pinned files use LF newlines.
- `case_indexes` is exactly `[0, 5, 6, 7, 8, 9, 10, 11]` in either report.
- `observations` contains exact JSON pointers and values. A verifier resolves
  every pointer against both reports and compares JSON values without numerical
  coercion or field substitution. Reconstructing the expected pointer set also
  verifies that no required case, stage, mode or source occurrence was omitted.
- `array_inventories` records the length of each projected active, provenance and
  relevant descendant array. The source serializer uses an empty object for some
  empty Lua collections; only that empty representation may also have length 0.
  Every active effect's identity and available group/source presence fields are
  retained, not only the two target families, so absence checks are meaningful.
- Relevant saved/runtime groups retain their whole bounded loader records.
  Active Sand, its Command and Firebolt retain exact source/group data and Sand
  minion ancestry/child identities. Large numerical output maps are omitted.
- `original_inventory` is an exact XML census of the two target families across
  all five fixtures, including manual counterparts. Ordinals are zero-based XML
  element preorder including the root. Attribute strings are retained verbatim;
  source `nil` tokens are not native defaults. Other families, including Water
  Djinn, are outside this packet's census.
- `baseline_imports` separately pins the current normalized drafts and sidecars
  from `runs/owned-global-energy-shield-03`. Its pointers retain exact preset IDs,
  raw generated-input bindings/completeness and usage completeness. This is
  historical import evidence, not a second runtime input path. Inventory status
  annotations summarize those exact provider joins and do not grant authority.

The packet contains 7,086 source observations, 186 array inventories, and fifteen
saved target-family occurrences: nine generated and six manual. Reconstruct the

values as runtime rules. Source reports and baseline imports are optional retained
