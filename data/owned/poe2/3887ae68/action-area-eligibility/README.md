lets ordinary typed rules inspect those identities. This packet uses those reads

queries, for eleven existing outputs covering fourteen stat sets. It adds no

with Area modifier eligibility. An unreviewed selection has no default producer.

a new Partial output owner. No whole-build or final radius/damage claim follows.

constructed: the selected stat-set base flags, compatible support additions,
part overrides and effect-specific/fallback map markers. The selected examples
alone do not prove the absence of dynamic writers. The optional runtime census
therefore checks the entire constructed skill/support catalogue and global map,
then all root/local maps and stat sets of these exact receivers.

diagnostics can differ from its earlier modifier-query bit. This packet does
not classify that difference as a game bug, use the late flag as authority for
an earlier query, or define a general-purpose intrinsic "Area skill" type.

to operations V20. Historical V4 migrations remain frozen at operations V19.
