# Ice Nova source-input fragments

This packet supplies ordinary owned rule programs for the physical Ice Nova
source, six observed support preparations, and the source-count condition on
Uhtred's Exodus. It targets the existing projected final-level slot `32d6`.
It does not close an owner inventory or publish an executable evaluation bundle.

The pre-support program reads the exact physical Gem's level, corruption delta
and explicitly selected ordinary quality. It computes `max(level + corruption,
1)` and then adds contributions from the declared global Spell-level channel.
Quality is preserved as a preparation input. Missing selected quality is not
replaced by zero. Physical Gem tags establish the scope of this Spell channel;
support-added types do not change the earlier eligibility predicate.

The final assembly runs with the physical Gem's original Actor producer context.
Its separate `PropertyOwner` destination reads the source's pre-support level and
adds retained source-property contributions after support admission and census.
It clamps to the proved dense range 1..40, preserves integral rows, and uses
natural maximum 20 for an interior fraction. Integer quantization only tests
integrality at this final boundary; intermediate fractions remain intact.
The result projects through the existing primary supply into `32d6`.

Exodus contributes three levels exactly when the sealed native source census is
one. The count is supplied by the checked source relation, not an authored constant
or a count of distinct Gem definition IDs. The fragment's finite applicability
is the physical Ice Nova source and already admitted retained support positions.
It does not replace the support admission model or implement the other Exodus
effects. Encroaching Ground, Magnified Area II, Rapid Casting I/II, Astral
Projection and Exodus use their own physical level and selected ordinary quality
for the existing preparation channels. Their source level tables are singleton
level 1. The owned raw Gem level schemas remain unchanged.

The three new definitions are source count `32e0` (Integer, Skill), supported
level additions `32e1` (Count quantity, Skill), and global Spell-level additions
`32e2` (Count quantity, Actor). The packet reuses preparation channels
`30ac..30af`, six existing support Gem schemas, and the existing Ice Nova supply,
grant, stat sets and intrinsic routes. V3 migration explicitly selects schema V5
and operations V18. There are nine new programs, no tables or query changes,
and no new final-quality slot because no corresponding consumer is implemented.

All seven affected owners remain Partial. In particular, this packet does not
supply the complete global Spell contributor inventory: a contribution reduction
with an empty value is not evidence that the real build has no contributors.
The separate native fixture may close an explicitly finite component with no
external contributors. The real release retains unresolved ordinary GemProperty
families, item-copy behavior, external SupportedGemProperty producers, supported
and final quality, general admission and full support mechanics. Full-build
coverage gates remain mandatory; whole-build native completion remains 0/5.

`dependencies.json` copies exact predecessor schema rows. Runtime programs in
`migration.json` use only owned operations and IDs. `bindings.json`,
`source-vectors.json` and `authoring.json` describe authoring and verification;
the runtime does not read source names or evaluate source-format expressions.
