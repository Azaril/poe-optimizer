# Reviewed source-role prerequisites

Apply this source-only successor after `source-condition-inputs`. It replaces all 29
remaining unconditional SingleModifier declarations with Unresolved fallback roles and
27 explicitly guarded rules. Together with the unchanged fixed-cold guard there are
28 conditional rules. Two bare direct-resistance ranges remain unresolved.

```powershell
poe-optimizer extend-owned-recipe PRIOR --extension data/owned/poe2/3887ae68/source-role-inputs/extension.json --items PRIOR/items.json --item-source data/owned/poe2/3887ae68/source-role-inputs/item-source.json --output NEW
```

Schema, registry, item recipes, numerical programs, receivers and query bytes stay unchanged.
The conditions are injected import compatibility declarations, not calculation programs.
Every newly guarded rule requires a structurally selected base with no generated members.

| Family | Raw capture proof | Initial source context |
| --- | --- | --- |
| Fixed Life, all-elemental resistance, flat critical chance | Explicit `+`, digit-led decimal, inclusive 0..1,000,000; the line recipe still controls integer/decimal syntax | Recognized non-scaling controls and empty source modifier tags |
| Increased/reduced qualifiers and flat damage, fixed or ranged | Each capture is unsigned integer 0..1,000,000 | Same empty-tag proof |
| Plus elemental-resistance range | Each endpoint is unsigned integer 1..1,000,000 | Same empty-tag proof |
| Plus cold-resistance range | Each endpoint is unsigned integer 1..1,000,000 | Empty tags, or a proven fresh prefix without a catalyst-setting header |

`NoSourceScalingTags` allows reviewed range/implicit/enchant/fractured/desecrated controls
and empty `tags` values. It rejects unknown controls, rune lifecycle, corruptedRange and
nonempty modifier tags. `InitialScalingIsOne` additionally admits nonempty tags only when
all earlier source context is proven and there was no catalyst-setting header. Unknown,
malformed, misplaced or duplicate context cannot establish absence. Owned defaults are not
consulted. Version 6 declines GGG markup globally because it can expose persistent advanced
controls and inject tags into later visually untagged lines.

The source's initial parse uses range 1. Saved range values and XML overlays remain separate
inputs with their existing validity and ordering gates. A zero selected range can produce
an empty final modifier cache despite a fully parsed initial source member. These proofs do
not establish final magnitude, numerical eligibility, affix legality or whole-build parity.
The old fixed-cold guard is unchanged. Signed negative domains, bare direct ranges, non-unit
catalyst contexts and source markup remain explicit follow-up work.
