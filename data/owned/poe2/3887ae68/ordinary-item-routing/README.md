# Ordinary item routing fragment

This packet changes ordinary Player delivery of the already admitted Minion-level
modifier `30ca` when the reviewed allocated Necromantic Talisman node is present.
It preserves the independent early Amulet copy program, its `32e3` eligibility,
and the pre-copy `32e4` snapshot. It does not implement a Minion GemProperty
consumer or close the Modifier, Passive, template, or whole-build inventories.

The predecessor is `runs/owned-sniper-population-readiness-01/package`, input
`4ce040d82ff5ed51801d46108fdb55b43f48820664a76b6f2575d8acaa116704`.
