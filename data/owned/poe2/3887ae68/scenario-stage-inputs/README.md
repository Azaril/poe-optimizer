# Scenario stage inputs

This packet retains the actual saved Sigil stage count and Corrupting Cry stack
count as typed Scenario-owned intent. It uses the existing native UsagePolicy
and exact Grant/SkillGrant identities. The source controls remain Import data.

Both applicability lists are nonempty and Partial. Sigil's physical Gem and
Chiming Staff item-modifier paths are distinct; Cry I, Paquate and Cry II retain
their distinct physical support sources and generated Skills. All four Skills,
the Sigil Gem and the new item Modifier remain Unmapped. Existing Cry
declarations and the Staff modifier list remain Partial. Supplied output lists
remain empty Partial sets, with no preset-input permission.

There is no activation program, Actor binding, final-level producer, stage Stat,
buff delivery, trigger, damage calculation or new default. Potential source
membership is not execution authority. The unresolved support-child proposal
is not implemented by this packet.

Sigil selects Input before Placeholder and preserves zero. Cry selects nonzero
Input before nonzero Placeholder. All present lanes are decoded and checked,
including losing candidates. Missing data, duplicate candidates, malformed
losing values and all-zero Cry values do not construct an intent. Raw values
are never capped or transformed into downstream multipliers. The integer bound
is representational rather than a claimed gameplay maximum.

The ordinary Rust tests read only this packet, authenticated existing source
archives, and checked-in fixtures. No test invokes PoB. The explicit ignored
authoring test reads the pinned current release and the earlier source handoff;
it refuses to overwrite authored JSON. Run it with
`POE_AUTHOR_SCENARIO_STAGE_INPUTS=1` and test
`author_scenario_stage_packet_from_current_predecessor`.

All five independent inventory obligations remain Pending. Only the exact
source leaves with proven intent destinations may lose their fallback links.
All-five publication and unchanged-input inverse checks are separate tests.
