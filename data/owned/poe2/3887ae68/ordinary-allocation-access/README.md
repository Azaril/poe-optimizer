# Independent saved allocation access

This optional tree policy classifies a saved allocation as ordinary access only
after a checked source-shape and positive-path proof. It adds no node, input value,
rule, cost, point entitlement, numerical result or whole-build readiness claim.

The domain is derived from the complete pinned tree catalogue. It contains 4,316
existing allocation definitions: 3,925 ordinary-pool and 391 ascendancy-pool nodes,
including 293 attribute nodes and 77 switchable stat views. Nodes with unlock
prerequisites, source free-allocation flags or alias-socket behavior are excluded.
Implicit roots, attached options and unsupported catalogue rows are separate roles.
The unchanged base-node constructor gives the admitted domain Normal, Notable,
Keystone or Socket types; Mastery transit is outside this reviewed profile.

Attribute and switchable replacement preserve identity and path structure. Their
stat effects remain unconverted where existing coverage says so. Target choices
must resolve independently. Shared paths use only positively listed saved nodes
and the selected class or ascendancy root. Scoped, exceptional and disconnected
nodes do not become transit shortcuts. Listed positive edges may be used even
when the enclosing schema set is Partial; no unknown edge or member is inferred,
and every existing schema gap remains unchanged.

`policy.json` is the typed injected runtime declaration. `authoring.json` binds
the exact predecessor, catalogue, exported source facts, token identities and
reviewed source functions. It records CalcSetup evidence separately from the
historical mapping source union. The optional field is installed inside the
already bound tree content, avoiding a normalization/tree digest cycle.

The Rust default regression checks the full catalogue-derived domain and exact
owned token joins. The real publication regression separately checks paths in
the immutable original sources, preserves all canonical/source relationships
with injective local-ID correspondence, and retains all 110 query rows. The
complete-source PoB witness supplies independent lifecycle/path evidence. None
of these checks claims numerical parity or complete original-build evaluation.
