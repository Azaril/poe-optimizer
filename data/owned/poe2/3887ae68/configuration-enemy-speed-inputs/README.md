# Configured enemy attack / cast interval

This data adds a typed Enemy scenario input for the configured interval in milliseconds. Unit `336f` is distinct from the existing seconds unit; input `3370` admits finite values from -1,000,000 to 1,000,000 milliseconds without clamping. Negative, fractional and zero values remain explicit input data. No enemy-speed modifier, action-speed calculation, survival-time formula or rule program is added here.

The existing configuration default adapter implements the source order: an authored numeric Input wins, including zero; otherwise the constructor supplies 700 milliseconds. A saved numeric Placeholder is parsed for validity but never supplies this value. The original `enemyIsBoss` callback resets that Placeholder unconditionally; the boss-skill callback can subsequently replace it. Consequently this packet is bound to the existing Encounter policy requiring `enemyIsBoss`, `presetBossSkills` and `enemySizePreset` to be absent in every saved lane. An explicit `None` is still a saved write and is not admitted by that policy.

`accounting.json` uses the common checked configuration receipts. The authored Input and overwritten Placeholder each need the exact scalar-input receipt for their source occurrence and Scenario. Only the Placeholder becomes source-only (`unused-config-placeholder`); unrelated configuration and source origins remain unresolved. The Encounter's external-input membership remains Partial, as do configuration inventories and every existing build obligation.

`source-evidence.json` authenticates the complete original files against the pinned PoB source manifest and records the full relevant callbacks, notification body, input declaration and original downstream consumer. Existing ConfigOptions, ConfigTab and EditControl source archives are reused; only CalcDefence is newly retained in this packet. Both retained observed traces corroborate constructor/default dispatch with JIT disabled; the separate unhooked scalar controls cover JIT off and on. These reports do not replace the source-body proof. No Lua execution is needed by ordinary tests or native use. Original source licensing is retained in [the shared source packet](../configuration-accounting/evidence/pob/LICENSE.md).

The ordinary Rust tests use committed data and fixtures. The separately ignored publication test requires the authenticated current release and a new output directory. It publishes the two descriptors and policy rows, rebuilds the result byte for byte, and checks all five original imports through exact draft and sidecar inverses, preserving local IDs, all 110 queries, unrelated origins and existing finalization obligations. It also checks real-build mutations of authored input, overwritten placeholders and unsupported boss settings.
