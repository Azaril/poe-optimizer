## Reproduction

Compile `cargo test --test owned_player_rule_ownership --no-run`, wait for it to
finish, then run the exact emitted test executable. Use the authored filter
`authored_player_ownership_moves_one_body_without_completing_game_rules`.
For the ignored publication test
`publish_player_rule_ownership_preserving_all_five_originals`, set
`POE_OPTIMIZER_TEST_PLAYER_RULE_OWNERSHIP_PRIOR` to the verified empty-MORE package
and `POE_OPTIMIZER_TEST_PLAYER_RULE_OWNERSHIP_OUTPUT` to a fresh directory.
The four ignored `ownership::native::` tests require
`POE_OPTIMIZER_TEST_PLAYER_RULE_OWNERSHIP_RELEASE` pointing to its new package and
`POE_OPTIMIZER_TEST_PLAYER_INTRINSIC_LIFE_RELEASE` pointing to
`runs/owned-player-intrinsic-life-01/package`.

committed in `source-vectors.json` and validated by the existing source helper
